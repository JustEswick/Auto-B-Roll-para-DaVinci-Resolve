DaVinci Resolve Scripting API Changelog
---------------------------------------

Last Updated: 13 October 2025

This file documents scripting changes by version.
For the overall DaVinci Resolve Scripting API, please refer to Developer/Scripting/README.txt.

API Changes by DaVinci Resolve version:
---------------------------------------

## 20.2.2

Added:
* ProjectManager.CreateProject parameter 'mediaLocationPath' to set project media location.
* Resolve.GetFairlightPresets()
* Timeline.ApplyFairlightPreset(preset_name)

Addressed:
* GetRenderCodecs(renderFormat) to return all applicable codecs.
* Handling of large trackIndex values for audio only AppendToTimeline calls.

## 20.2.1

Addressed:
* TimelineItem.GetName() for subtitle clips to return subtitle text instead of clip type.
* Project.SetSetting() failure when setting ACES 2.0 IDTs and ODTs.

## 20.2

Added:
* MediaPoolItem.SetName(new_name)
* TimelineItem.SetName(new_name)
* TimelineItem.ResetAllNodeColors()   for the active version.
* Project.SetRenderSettings keys 'ExportSubtitle' and 'SubtitleFormat' for render jobs with subtitles.

## 20.1

Added:
* Timeline.GetVoiceIsolationState(trackIndex)
* Timeline.SetVoiceIsolationState(trackIndex, {VoiceIsolationState})
* TimelineItem.GetVoiceIsolationState()
* TimelineItem.EnableVoiceIsolationState({VoiceIsolationState})

Addressed:
* Interlaced clip frame offset issues in multiple APIs.

## 20.0.1

Addressed:
* MediaPool.AppendToTimeline not working in some scenarios.

## 20.0

Added:
* MediaPoolItem.LinkFullResolutionMedia(fullResMediaPath)
* MediaPoolItem.ReplaceClipPreserveSubClip(filePath)
* MediaPoolItem.MonitorGrowingFile()

Addressed:
* TimelineItem.GetRightExtents return (it now returns offset between right edit point and media extents end).
* Occasional lags for some scripting APIs.
* AddFusionComp sometimes showing incorrect composition.
