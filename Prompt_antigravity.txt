# [INFORMACIÓN DEL PROYECTO]
**Nombre del Proyecto:** Auto-B-Roll para DaVinci Resolve
**Descripción General:**
Un sistema de automatización diseñado para agilizar la edición de videos tipo "talking head" (bustos parlantes). El software debe analizar el audio del video principal, entender el contexto semántico (de qué se está hablando) y buscar automáticamente material visual de apoyo (imágenes o videos de stock) para superponerlos en la línea de tiempo.

**Flujo deseado:**
1. Usuario carga video en DaVinci Resolve.
2. El script analiza el audio (Speech-to-Text).
3. Identifica palabras clave o conceptos visualizables.
4. Busca y descarga assets libres de derechos (o de librerías conectadas).
5. Importa y coloca los assets en la línea de tiempo sincronizados con la palabra hablada.

**Restricciones y Requisitos Técnicos:**
* **Core Software:** Debe funcionar obligatoriamente sobre **DaVinci Resolve 20** (o versión más estable reciente, 19).
* **Método de Integración:** Uso de la **DaVinci Resolve Scripting API** (Python).
* **Entorno:** Ejecución local en escritorio (no es una web app SaaS por el momento).
* **Assets:** Debe priorizar el uso de APIs de stock gratuitas o accesibles para el MVP.
